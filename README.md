# 🏧 Python ATM Simulator

A simple console-based ATM system built using Python.  
This project simulates real ATM functionality including login, balance checking, deposits, and withdrawals.

---

## 📌 Features

- 🔐 PIN authentication system
- 💰 Check account balance
- ➕ Deposit money
- ➖ Withdraw money with balance validation
- 🚪 Exit system safely
- 🔁 Continuous menu loop until exit

---

## 🧠 How It Works

1. User inserts card (simulation)
2. Enters PIN for authentication
3. If correct, ATM menu appears:
   - Check Balance
   - Deposit
   - Withdraw
   - Exit
4. User interacts until they choose to exit

---

## 🛠️ Technologies Used

- Python 3
- Conditional statements (`if/elif/else`)
- Loops (`while`)
- User input handling
