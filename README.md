🏧 ATM Banking System
A simple Python ATM simulator that allows users to log in using a PIN and perform basic banking operations like checking balance, depositing money, and withdrawing cash.
✨ Features
🔐 PIN authentication system
⛔ Limited login attempts (security feature)
💰 Check account balance
➕ Deposit money
➖ Withdraw money
🚪 Exit system
🧠 What I Learned
🐍 Python basics
🔁 While loops
❓ If/else statements
⌨️ User input handling
🏗️ Building simple real-world logic systems
🚀 How It Works
Insert card and enter PIN
If correct → access granted
If wrong → attempts decrease
After 5 wrong attempts → account is blocked
Once inside, user can use ATM menu options
